### Пути и запуск

### MiningEngine
- **Anti-cheat:** 15 кликов/сек
- **Чанковая система:** поверхность 15×15×10 (2250 блоков) + шахтные чанки 5×5×5 (125 блоков)
- **Mine Shafts:** проход 3–5 блоков вниз при открытии
- **Блоки CanCollide:** не пройти сквозь
- **Блоки не респавнятся** — дыра навсегда до перезахода
- **Чанки по центру копания** — где игрок копает, там и новые блоки
- **Глубина:** прогресс-метры, не сдвигает блоки

### Графика
- **Damage Numbers:** всплывающие цифры при ударе (крит — жёлтый, жирный)
- **HP Bar:** при наведении, с цветом (зелёный→жёлтый→красный) и текстом
- **Hover:** золотая рамка + белая подсветка
- **Редкость:** цветной индикатор над блоком, тоглится `/rarity`
- **Блок 3×3×3 студа**
- **Команды:** `/rarity`, `/hpbar`, `/help`

### Экономика

### Документация

## Решения
- Глубина (depth) — прогресс-метры для разблокировки слоёв, не трогает видимые блоки
- Поверхность фиксирована (Y=0..9, 15×15)
- Шахтные чанки генерируются лениво при углублении
- При перезаходе — шахта полностью свежая
- Signal — свой модуль (не Wally)

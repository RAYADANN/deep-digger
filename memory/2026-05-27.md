# 2026-05-27 — Старт проекта Deep Digger

## Решения

- **Аналог:** [FISHING🐟] Infinite Mining Incremental ⛏️ (StellarScript)
- **Название:** Deep Digger 🪨
- **Сроки:** 1–2 месяца, упор на качество
- **Рендер:** 3D Part'ы на клиенте, сетка 25×25, 300 видимых блоков
- **Шахта:** своя у каждого игрока, чужие Part'ы не видны
- **Архитектура:** Rojo + Wally, сервер → только данные, клиент → Part'ы
- **Библиотеки:** ProfileService, Net, Fusion, Promise, Signal, Llama, Lune
- **Модульность:** каждый модуль можно вытащить в другой проект
- **Слои:** открываются глубиной (как в Minecraft), не прогресс-баром
- **Mine Shafts:** постоянные, 6% шанс, +0.5% к редкости руд за каждую

## Стек
- Rojo (синхронизация)
- Wally (пакеты)
- Fusion (UI)
- ProfileService (DataStore)
- Net (сеть)

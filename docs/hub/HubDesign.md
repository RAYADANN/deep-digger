# Hub Design — Deep Digger 🪨 (Fantasy / Premium)

> Дизайн-спека хаба (зона спавна на поверхности). «Чертёж», по нему хаб строится в Studio через MCP. Код игры этим документом **не трогается**.
> Тема: **Фэнтези-рудник** — серый камень + золото + магическое свечение кристаллов. Уровень: **Premium** (детали, вагонетки, фонари, баннеры, руны, частицы).
> Стиль геометрии: **Low Poly**.
> Обновлено: 2026-06-05

---

## 0. Жёсткие факты о мире (не менять — под них подгоняем хаб)

Шахта = поверхностное поле блоков, в которое игрок копает **вниз**. Координаты из `constants.lua` (`BLOCK_SIZE_STUDS = 4.5`, `SURFACE_W/D = 15`) и Z-оффсета `+30` в `MiningRenderer`.

| Параметр | Значение (studs) |
|---|---|
| Размер блока (BS) | 4.5 |
| Центр шахты (X, Z) | **(0, 30)** |
| Верх поля шахты (Y) | **0** |
| Поле по X (грани) | от **-33.75** до **+33.75** (≈ 67.5) |
| Поле по Z (грани) | от **-3.75** до **+63.75** (≈ 67.5) |

**Правило №1:** хаб **обрамляет** яму, но НИКОГДА не накрывает `X ∈ [-33.75, 33.75], Z ∈ [-3.75, 63.75]` сверху — иначе нельзя копать.

## 1. Структура (иерархия в Workspace) — это «профессиональность»

Не свалка партов, а чистое дерево. Каждый составной объект — `Model` с `PrimaryPart`, осмысленные имена.

```
Workspace/
└── Hub/                         (Model, PrimaryPart = Plaza floor)
    ├── Plaza/                   пол площади + бордюр ямы + дорожка
    ├── Spawn/                   пьедестал + SpawnLocation + колонны
    ├── MineEntrance/            арка, руны, кристаллы, частицы, бордюр-свет
    ├── Shops/
    │   ├── ShopStall/           лавка-магазин (навес)
    │   └── EggPedestal/         пьедестал яйца
    ├── Leaderboard/             доска топа
    ├── Props/                   вагонетки, рельсы, фонари, баннеры, бочки, кирки
    ├── Environment/             холмы, скалы, деревья, мох
    └── Lights/                  PointLight'ы (Shadows=false)
```

## 2. Палитра (фиксируем — используем ВЕЗДЕ)

Правило: **≤6 цветов на сцену**, **≤4 материала**. Тема — благородный камень + золото + магия.

### Материалы (только эти)
- `Slate` — камень (площадь, бордюр, скалы, колонны).
- `SmoothPlastic` — основной декор, дерево, ткань, металл.
- `Foil` — золото (капители колонн, оковка, экран лидерборда).
- `Neon` — **только** свечение (кристаллы, руны) — мало штук, декоративно (Neon с игровых блоков убран ради FPS, тут безопасно при низком числе).

|---|---|---|---|
| Камень площади (холодный серый) | `#6B6E78` | 107, 110, 120 | настил вокруг ямы |
| Тёмный камень (база/бордюр) | `#3E4049` | 62, 64, 73 | рамка ямы, цоколь, скалы |
| Брусчатка дорожки | `#878A93` | 135, 138, 147 | путь спавн → шахта |

## 5. Освещение (не ломать игру)

Глобальным `Lighting` уже управляет `client/core/LayerEnvironment` (твинит Ambient/Brightness/ClockTime/Atmosphere по глубине; на поверхности — яркий «dirt»-пресет, Фаза 14).

- Глобальный `Lighting` через MCP **не переопределяем**.
- Можно: локальные `PointLight` на фонарях/кристаллах/sell-pad — **`Shadows = false`**, низкий `Range/Brightness`, общее число под капом (по духу `OptimizationLog`).
- `Atmosphere` — только если в сцене его нет; лёгкий (`Density ~0.3`, `Haze ~1`), проверить отсутствие конфликта с твином слоёв.

## 6. Бюджет производительности

- Цель: хаб **не должен ронять FPS**. Декор — Anchored, `CastShadow = false`, `CanTouch = false` где не нужно.
- Источники света суммарно: **≤ 12**, все без теней.
- Neon-парты (кристаллы/руны): **≤ ~30** мелких.
- Частицы: 2–3 эмиттера (вход + пара фонарей), низкий Rate.
- Деревья/скалы — простые парты/юнионы, не тяжёлые меши.

---

## 7. Чек-лист «хаб готов»

- [ ] Спавн на пьедестале, игрок **сразу видит вход в шахту** впереди.
- [ ] Поле шахты ничем не накрыто — копать можно с первого клика.
- [ ] Иерархия `Workspace/Hub/...` чистая, у моделей есть `PrimaryPart`.
- [ ] Палитра выдержана: ≤6 цветов, ≤4 материала.
- [ ] Вход в шахту — самый заметный объект (золото + бирюзовые кристаллы + руны + частицы).
- [ ] Граница из скал/холмов/деревьев — нет «обрыва в пустоту».
- [ ] FPS не просел: свет без теней, ≤12 источников, Neon ≤30.
- [ ] Глобальный `Lighting` не переопределён (живёт `LayerEnvironment`).

---

## 8. Порядок постройки (через MCP, когда Studio подключён)

1. Создать `Workspace/Hub` (Model) и под-папки (Folder/Model).
2. Грейбокс: пол + бордюр ямы + дорожка + спавн-пьедестал (серые блоки) → проверить, что поле не накрыто и спавн смотрит на шахту.
3. `SpawnLocation` на пьедестале.
4. Вход в шахту: арка + светящийся кант + кристаллы + руны + частицы + табличка.
5. Колонны спавна, sell-pad.
6. Лавка, пьедестал яйца, доска лидерборда.
7. Props: вагонетки/рельсы, фонари, баннеры, бочки/кирки.
8. Окружение: скалы, холмы, деревья, мох.
9. Полировка: цвета по палитре, материалы, локальный свет, частицы; финальный проход по чек-листу §7.

# UI assets (Rojo → ReplicatedStorage.uiAssets)

Сгенерированный набор иконок в едином cartoon-стиле (256×256 PNG).

| Файл | HUD |
|------|-----|
| `coin.png` | Валюта |
| `depth.png` | Глубина |
| `tab_*.png` | Кнопки dock / sell |
| `upg_*.png` | Строки апгрейдов |
| `buff_*.png` | Бафы питомцев / предметов (BuffBar) |
| `icon_*.png` | Уведомления, магазин |
| `icon_robux.png` | Цена в Robux |
| `pack_*.png` | Hero-наборы в магазине |

После правки: Rojo sync. Для продакшена — upload в Creator Hub → id в `UiAssets.lua` → `FALLBACK_IMAGES`.
